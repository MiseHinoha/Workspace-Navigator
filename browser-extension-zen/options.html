📖 如何获取 Token

1

打开导航页

访问你的 Workspace Navigator 并登录

2

打开开发者工具

按 F12 或 Ctrl+Shift+I

3

找到 Token

切换到 Application/存储 → Local Storage → 复制 token 的值

4

粘贴保存

将 Token 粘贴到上方输入框并保存

💡 提示：Token 相当于你的登录凭证，请勿分享给他人。
