# 浏览器扩展本地安装指南（无需签名验证）

本指南提供**无需发布到商店、无需签名验证**即可在本地使用扩展的方法。

---

## 🔷 Chrome / Edge 安装方法

Chrome 已禁止直接安装 .crx 文件，请使用以下方法：

### ✅ 方法：加载已解压的扩展程序（推荐）

**步骤：**

1. **打开扩展管理页面**
   - 地址栏输入：`chrome://extensions/`
   - 或点击菜单 → 更多工具 → 扩展程序

2. **开启开发者模式**
   - 打开右上角的「开发者模式」开关

3. **加载扩展**
   - 点击「加载已解压的扩展程序」
   - 选择 `browser-extension-chrome/` 文件夹
   - 点击「选择文件夹」

4. **完成**
   - 扩展会立即加载，无需签名！
   - 扩展图标会出现在工具栏

**示意图：**
```
chrome://extensions/
├─ [开] 开发者模式
├─ [加载已解压的扩展程序] ← 点击
│   └─ 选择 browser-extension-chrome/
└─ ✅ Workspace Navigator 已加载
```

## 🔶 Zen / Firefox 安装方法

### ✅ 方法1：临时加载（最简单，推荐测试用）

**步骤：**

1. **打开调试页面**
   - 地址栏输入：`about:debugging#/runtime/this-firefox`

2. **加载扩展**
   - 点击「临时载入附加组件...」
   - 选择 `browser-extension-zen/manifest.json`
   - 点击「打开」

3. **完成**
   - 扩展立即加载！

**注意：** 重启浏览器后扩展会消失，需要重新加载。

---

### ✅ 方法2：允许未签名扩展（永久安装）

如果你想永久安装未签名的 .xpi 文件：

**步骤：**

1. **修改配置**
   - 地址栏输入：`about:config`
   - 点击「接受风险并继续」
   - 搜索：`xpinstall.signatures.required`
   - 双击将其值改为 `false`

2. **安装扩展**
   - 打开 `about:addons`
   - 点击齿轮图标 → 「从文件安装附加组件...」
   - 选择 `workspace-navigator-zen-v1.0.0.xpi`

3. **完成**
   - 扩展永久安装，重启后依然有效！

**注意：** 此设置会降低安全性，建议仅在个人电脑使用。

## 🚀 快速安装（使用批处理脚本）

我们提供了自动化的安装助手：

### Windows 用户

```bash
# Chrome 安装
cd browser-extensions
install-chrome.bat

# Zen 安装
cd browser-extensions
install-zen.bat
```

脚本会自动打开浏览器页面并给出操作指引。

## ❓ 常见问题

### Q: Chrome 提示"无法从该网站添加应用、扩展程序和用户脚本"？
**A:** 这是正常的安全限制。请使用「加载已解压的扩展程序」方法，这是 Chrome 官方支持的方式。

### Q: Zen 重启后扩展消失了？
**A:** 临时加载的扩展会在浏览器重启后失效。如需永久使用，请参考「方法2：允许未签名扩展」。

### Q: 为什么 .crx 和 .xpi 文件无法直接安装？
**A:** 
- Chrome 80+ 版本已禁止从文件系统安装 .crx
- Firefox/Zen 要求扩展必须经过 Mozilla 签名才能永久安装
- 这是为了用户安全，防止恶意扩展

### Q: 开发者模式有什么风险？
**A:** 开启开发者模式本身没有风险，只是启用了一些高级功能。但请只加载你信任的扩展。

### Q: 能否自动更新？
**A:** 本地安装的扩展不会自动更新。如需更新：
- Chrome：删除旧扩展，重新加载新版本
- Zen：重新临时加载，或重新安装 .xpi

## 📁 文件说明

| 文件/文件夹 | 用途 | 安装方式 |
|------------|------|----------|
| `browser-extension-chrome/` | Chrome 扩展源码 | 加载已解压 |
| `browser-extension-zen/` | Zen/Firefox 扩展源码 | 临时加载 |
| `dist/*.xpi` | Zen 打包文件 | 允许未签名后安装 |
| `dist/*.crx` | Chrome 打包文件 | 已废弃，不推荐 |
| `install-chrome.bat` | Chrome 安装助手 | 双击运行 |
| `install-zen.bat` | Zen 安装助手 | 双击运行 |

## 🛠️ 故障排除

### Chrome 扩展不显示图标？
- 点击扩展管理页面的「刷新」按钮
- 或重启浏览器

### Zen 提示扩展损坏？
- 这是未签名扩展的正常提示
- 点击「修复」或「仍然安装」即可

### 扩展无法连接后端？
- 检查导航页地址配置是否正确
- 确认后端服务已启动
- 检查浏览器控制台错误信息
